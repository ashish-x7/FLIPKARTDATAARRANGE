      2-File Processor Rules

      New: 2 Files Rule

      Required Uploads (Exactly 2 Files per Party):

      • DropShip File: Contains FLIPKART_MERGED_ORDERS, DropShip, or Seller_Orders_Report.
      • IndoPrimo File: Contains SaleData, IndoPrimo, or Sale Item Details.

      Automated Execution Pipeline:

      1. Dictionary Match: Builds key =B3&G3 from IndoPrimo file.
      2. DropShip Filter: Matches =G2&E2 (or Col DW) and deletes matched rows.
      3. Date & Metadata: Calculates Date Range & B2/P2 values.
      4. GST Not Applicable: Auto-detects 0/missing tax rate, creates [Party]-GST NOT APPLICABLE.xlsx with shaded rows & 5% adjusted tax.
      5. Invoice Range: Extrapolates Min and Max from Col G (EE Invoice No) e.g. 101-(2-9).
      6. Duplicate Invoices: Checks duplicate invoices in Col G, exports [Party]-2 MORE INVOICE.xlsx.
      7. 18-Column OD Master: Generates standard 18-column Master Combined sheet.
      8. Clean DT File: Compiles DT workbook with cell highlights.

      Invoice Arrange Process

      Required Uploads (Exactly 3 files):

      • OD File: Contains FLIPKART_MERGED_ORDERS in the filename.
      • DT File: Contains TaxReportData in the filename.
      • Details File: Contains -FLIPKART and prefix (e.g. 101-Bharvita-FLIPKART...).

      Execution Steps:

      1. Matches Details file's Invoice No (Column B) in DT (Column G) and **deletes matched rows**.
      2. Calculates suffix range (e.g. 1-9) and saves remaining DT to a new file (e.g. 101-(2-9)-DT.xlsx).
      3. Highlights matching rows in OD (Column A) using DT's suborders (Column E) and exports them to a new file (e.g. 101-(FK27S101-2-9)-OD.xlsx).
      4. Performs VBA clean macro to export **GST NOT APPLICABLE.xlsx** (if Col G is not empty and Col AP is empty) and **2 MORE INVOICE.xlsx** (if duplicate invoices exist).
